# 屋邨仔｜ESTATE KID

《屋邨仔》是一款向 Game & Watch 掌上機致敬的單色 LCD 網頁小遊戲。故事發生在 1990 年代香港公共屋邨：放學後守住十四樓走廊，擊退左右逼近的小混混，同時千萬不要打中經過的阿婆。

## 玩法

- 敵人會由左右走廊逐格逼近；面向正確方向，在敵人到達最近一格時按 A 攻擊。
- 按 B 可格擋一次攻擊，成功時會把敵人彈後一格；使用後需冷卻三個節拍。
- 阿婆會由走廊一端走到另一端。讓她安全通過；打中她會扣三分並記一次 MISS。
- 普通敵人值一分，大佬需要打兩次並值五分。三次 MISS 後遊戲結束。
- `GAME A` 節奏較慢，`GAME B` 更快、敵人及阿婆更密集，`TIME` 顯示 24 小時制時鐘。

## 操作

| 操作 | 鍵盤 | 畫面按鈕 |
| --- | --- | --- |
| 轉向 | `←`／`→` | 十字方向掣 |
| 攻擊 | `Z` 或 `J` | A |
| 格擋 | `X` 或 `K` | B |
| 開始 | `Enter` | START |
| 切換模式 | 右 `Shift` | SELECT |
| 靜音／開聲 | 長按右 `Shift` 一秒 | 長按 SELECT 一秒 |

手機直向及橫向均可遊玩；所有觸控與鍵盤操作可同時使用。

## 執行與部署

不需安裝、建置或連線。直接用瀏覽器開啟專案根目錄的 `index.html` 即可遊玩。部署至 Cloudflare Pages 時，將輸出目錄指向專案根目錄並留空建置指令。

## 程式架構

整個作品只有一個 `index.html`，沒有框架、套件、外部字型、圖片、音檔或網絡請求。

- `SEGMENTS`：Canvas 2D 液晶區段及七段顯示器；亮起與熄滅只改變透明度。
- `STATE`：模式、分數、敵人、阿婆、MISS、格擋冷卻等單一狀態。
- `tick()`：以固定節拍推進敵人、阿婆及生成邏輯。
- `render()`：按狀態重繪固定座標的 LCD 區段，沒有逐幀補間。
- `input`：共用觸控、指標及鍵盤輸入。
- `audio`：以 Web Audio API 即時合成方波蜂鳴器音效。
